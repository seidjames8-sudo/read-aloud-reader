# Read Aloud – Immersive Reader

Static site for GitHub Pages. The reader is a single file: `index.html`.

## Deploy
1. Create a new public repository on GitHub (for example `read-aloud-reader`).
2. Upload the contents of this folder (`index.html`, `.nojekyll`) to the repository root.
3. Go to Settings → Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute, the site opens at `https://<your-username>.github.io/read-aloud-reader/`.

YouTube players only run when the page is opened at this web address, not from a saved file.
