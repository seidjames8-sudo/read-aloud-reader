# Chapter Reference Block (fill per chapter)

Every reference must point to something that happens in this chapter. Each entry names the scene it supports. If a character, place, or event is not in the chapter text, do not add a reference for it.

## Rules
- One entry per event or character that appears in the chapter.
- Articles: only the character, place, or event named in the chapter, on the wiki that covers that franchise.
- Comic clips: only official pages or panels from the named issue or chapter.
- YouTube: only verified official trailers, creator interviews, or canon clips. Use a real video ID from the source page. Never guess an ID.
